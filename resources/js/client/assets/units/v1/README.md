# Unit thumbnail artwork — provisional v1

Generated 2026-09-20 with the built-in image-generation tool, one call per unit. These five illustrations match the current case names in `app/Domain/DivisionType.php`: Infantry, Armored, Artillery, Fighter and Bomber. No new unit types or mechanics are implied.

Original full-resolution square PNGs are retained unchanged. Gameplay and the foundation gallery now use 256 × 256 WebP delivery variants (`infantry.webp`, `armored.webp`, `artillery.webp`, `fighter.webp`, `bomber.webp`), about 36 KB combined. Variants were mechanically resized/compressed with ImageMagick at quality 82; the artwork itself was not regenerated or altered. Small-card desktop/mobile readability has been visually reviewed. Do not import the full-size masters into the live catalogue.

The mid-20th-century equipment treatment is a provisional art choice, not an agreed technology progression or specific faction. Labels, costs, maximum counts, selection, borders and unavailable state belong to live DOM/CSS, not these images. Future visual lookup should use stable division type names, with a labelled fallback; no costs/rules belong in the asset registry.
